# 本轮维护与后续集成

本页以下为先前流程的历史记录。当前决定已改为退出点评，仅集成小红书和官方高德，见[本轮验收](review-followup-2026-10-18.json)。

2026-10-18：三个仓库补齐 [开发、实测与PR交付](development-delivery.md)、[审查处理](review.md)、六段式PR模板及固定Action提交的Windows/Python3.14.8自动检查。日常主环境仍用已验收的固定依赖。

小红书候选0.1.1补有界搜索到50条与安全验证跳转识别。工具仓中记录上游437个PR/428个Issue索引筛查及重点取舍；本地已真实读取30条唯一搜索结果、排序和两篇正文/评论样本。
工具PR尚未合并时，本仓不静默改锁文件指向开发提交。它合并后，另开主仓依赖更新PR，固定真实合入的Git SHA，执行uv sync --locked、离线规划检查及真实研究烟测，更新同一套验收记录。

点评其他项目的分类/商圈过滤、推荐菜和JSON-LD/评论页方案仍是待验证候选。后续独立性验收实际发现一次页面就绪后的验证跳转，本次只修正该状态的识别，不替换读取路径。

独立性复核确认两个工具的库与 CLI 都可单独安装；Trip 持有业务适配，工具保留平台参数。两个工具的 CI 新增只装自身 wheel/依赖的隔离检查。小红书补浏览器冷启动首页初始化；Trip 显式映射当前工具的安全错误码，遇登录/验证停止受影响来源并保留证据。当前候选本地共120项测试通过。

新候选 wheel 的真实集成取得两篇小红书正文/评论样本，点评搜索5家、详情为 verification_required；完整整链仍待人工验证。详情与代码SHA见[本次验收](standalone-acceptance-2026-10-18.json)。这不是主锁文件已经部署候选的声明，也没有重新请求地图或天气。

微博确认存在 [官方weibo-cli](https://open.weibo.com/cli/quickstart)，与同名第三方Python项目不同。官方文档列出Node.js18+、OAuth、开发者认证及服务/额度前提。本轮只确认与规划，没有安装、登录、购买或接入主仓。
